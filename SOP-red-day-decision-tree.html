Red Day Decision Tree

A 90-second self-check for after a rough trading day. Answer honestly at each step — the tree tells you where you land.

0/4 checks run

Run every check in order. The first "yes" is your bucket — stop there.

  1. 1

    Was the setup correct?

    Check the machine

    Confirm before you judge the strategy. This is where most false alarms live — a disabled row or a sync miss looks exactly like "the algo broke" until you check it.

    • Correct account and contract are running
    • Strategy row is enabled and synced
    • No unexpected open position
    • No connection or log warnings
    If NO to any of these → Review Setup. Stop here, fix the setup, then re-check the day.
  2. 2

    Was the loss inside the plan?

    Check the risk

    Uncomfortable does not always mean broken. A loss that respects your planned daily/weekly risk is a normal outcome of a rules-based system, not a signal to intervene.

    • Daily loss stayed within your planned risk range
    • No rule violations occurred
    • Drawdown cushion still has meaningful room
    If YES → Keep Running. Nothing to do. Red does not always mean broken.
  3. 3

    Is the account still valid, but the cushion thinner?

    Protect the account

    The account hasn't broken any rule and isn't blown — but it's carrying less room than it was. This is a sizing/exposure decision, not a panic decision.

    • Account is still valid and tradeable
    • Drawdown cushion is meaningfully thinner after a rough stretch
    • You're close enough to drawdown that full size no longer makes sense
    If YES → Reduce Risk. Cut size, accounts, or aggression. Protect first, recover second.
  4. 4

    Are emotions or uncertainty driving decisions?

    Protect the decision quality

    This is the step members skip most — and the one with the highest cost when skipped. The urge to "win it back" is the tell.

    • You feel the urge to add accounts or size to make it back
    • You're frustrated, staring at every tick, tempted to intervene manually
    • You're not sure what's even running anymore
    If YES → Pause. Step back before you make a bigger mistake. If none of the 4 checks fired, the correct call is Keep Running.
✓

Check complete

You've run the tree in order. Land on the first bucket that matched — that's your action for today. If you landed on Review Setup and it doesn't resolve, file a support ticket with the account, strategy, and what the log showed.
